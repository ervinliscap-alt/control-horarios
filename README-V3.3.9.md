# V3.3.9 — Optimizador de dotación y desfases
- Evalúa automáticamente las 49 combinaciones de desfases (0–6 / 0–6) para planes de dos cajones.
- Recomienda la combinación con mayor cobertura y, a igualdad, menor carga máxima.
- Mantiene separados los semáforos de Cobertura, Descanso/Fatiga y Carga laboral.
- El umbral de 240 h es una advertencia operativa parametrizable, no una conclusión jurídica.
- La recomendación no modifica el plan hasta pulsar “Aplicar desfases recomendados”.
